PhoneDeck 1.5.0: the first DarkRelay release.

PhoneDeck runs your Android phone's apps in windows on your PC. Pick an app from a searchable list and it opens on your desktop, on a virtual display, while the phone's own screen stays free. Type with your PC keyboard, click and scroll with the mouse, pin favorites, keep several apps open in tabs, and drag files onto the window to send them to the phone. Free, local, built on scrcpy.

## What's new since the earlier private builds

- **New icon:** a relay-node phone riding a skateboard, drawn for every size from the taskbar up.
- **About box and Help > Licenses:** who made it, what it's built on, and the full license text of every component it ships.
- **Updates that check themselves:** PhoneDeck looks for a new release a few seconds after it starts (turn it off in Settings > Updates). A new version shows as an Update button in the status bar, never a pop-up, with Release notes, Download and install, Skip this version and Later. The download is checked against its published SHA-256 before anything runs; then PhoneDeck closes, updates itself silently and opens again.
- **Steadier:** clicking Reconnect, Refresh or a second file drop while one is still running no longer trips it up (a second drop waits its turn and still goes through). A missing scrcpy or adb now says plainly which file is missing and where PhoneDeck looked, instead of "No device found". If scrcpy can't start or the virtual display never shows up, PhoneDeck tells you instead of failing quietly.
- **Smoother details:** scrolling is centered on the display at any resolution and orientation; turning off Wi-Fi or switching on Airplane mode while connected wirelessly asks first, since that cuts the connection; each app can remember its own launch orientation, flipped ones included; and the interface falls back cleanly to a standard font when its preferred one isn't installed.
- **Bundled scrcpy 4.1 and adb:** nothing else to install on the PC. PhoneDeck finds them next to itself, or on PATH.
- **Open source under the Apache License 2.0**, with the third-party notices in the program and in this repository.

## Requirements

- Windows 10 or 11, 64-bit.
- An Android phone with USB debugging or wireless debugging turned on. No root, nothing to install on the phone.

## Install

Download PhoneDeck-Setup.exe (or PhoneDeck-Setup-1.5.0.exe) and run it. It installs to Program Files and upgrades an earlier PhoneDeck in place; your settings and favorites stay. PhoneDeck-Setup-1.5.0.exe.sha256 holds the installer's SHA-256 checksum.

The installer isn't code-signed, so Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
